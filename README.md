# Carbon_Emission_Prediction

# 🌍 Carbon Emission Prediction Project

## 📌 Overview

This project focuses on **predicting carbon emissions** using historical and socio‑economic data. The goal is to analyze emission trends, identify key contributing factors, and build a machine learning model that can accurately predict future carbon emission levels. This project highlights the role of data science and machine learning in addressing real‑world environmental challenges.

---

## 🎯 Objectives

* Analyze historical carbon emission data
* Perform data cleaning and preprocessing
* Identify important factors influencing carbon emissions
* Build and evaluate a predictive machine learning model
* Visualize trends and model performance

---

## 🗂️ Dataset

The dataset includes features such as:

* Country / Region
* Year
* Population
* GDP / Economic indicators
* Energy consumption
* CO₂ emissions (target variable)

> Note: The dataset was preprocessed to handle missing values, outliers, and inconsistent entries.

## 🔍 Methodology

1. **Data Preprocessing**

   * Handled missing values
   * Feature scaling and normalization
   * Encoding categorical variables

2. **Exploratory Data Analysis (EDA)**

   * Trend analysis over years
   * Correlation analysis between features
   * Visualization of emission patterns

3. **Model Building**

   * Train‑test split
   * Regression models (e.g., Linear Regression / Random Forest)
   * Hyperparameter tuning
   * Link to the Model: 
      https://drive.google.com/file/d/1Om5YrYAdNNXw-wyv7hXyr3NX-VDYk3NW/view?usp=drive_link
     
4. **Model Evaluation**

   * Mean Absolute Error (MAE)
   * Mean Squared Error (MSE)
   * R² Score

   ```

   ```


3. Install dependencies

   ```
   pip install -r requirements.txt
   ```

4. Run the notebook or script

   ```

   ```
